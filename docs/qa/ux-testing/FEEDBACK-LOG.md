# onService PH — Feedback Log

Keep this open next to the app while you test. Every time something makes you
**pause, frown, smile, or go "huh?"**, copy the block below and fill it in. Don't
wait until the end, you'll forget the small stuff, and the small stuff matters.

You don't need to be technical. Write like you'd text a friend. A screenshot is
worth a hundred words, so grab one whenever you can (on a phone, press the power
and volume-down buttons together; on a laptop, use the snipping tool).

## How to rate "how bad is it"

- **Blocker** — I could not continue. The thing was broken or stuck.
- **Major** — I got through it, but it was painful, confusing, or felt wrong.
- **Minor** — small annoyance, typo, or rough edge.
- **Idea** — not a problem, just a suggestion (feature, service, price, design).
- **Praise** — something you genuinely liked (tell us, so we don't break it).

---

## Copy this block for every item

```
Item #:
Area:            (Customer / Provider / Admin)
Type:            (Bug / Friction / Idea / Service idea / Price idea / Praise)
How bad:         (Blocker / Major / Minor / Idea / Praise)
Where I was:     (which screen or step, e.g. "booking - choosing the date")
What happened:   (in your own words)
What I expected: (what you thought would happen instead)
To see it again: (if it's a bug: what taps lead to it? only if you can repeat it)
Device/browser:  (e.g. iPhone Safari, Windows Chrome)
Screenshot:      (file name, or "none")
```
